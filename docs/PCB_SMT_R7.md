# R7：统一检查状态、后台对象与 PCB/Gerber/BOM → SMT

## 统一状态

每个检查键有一个权威 `inspection_states`：数据阶段（未获取/已取得/已检查/部分检查）和判定（不符合/需复核/满足当前检查范围）。
逐位置记录作为证据保留，失败不被覆盖。Gerber 已完成扫描后撤去旧参数“未获取”占位行；缺顶/底面时对应范围仍显示未获取。
数据可用率不等于算法覆盖率；部分检查和 `geometry_complete=False` 仍阻止全板放行。PCB Excel 新增“统一检查状态”。

## 后台对象

新增 COMPONENT_PIN、COMPOSITE_PAD、FULL_GEOMETRY、COMPONENT 四视图：引脚原点/网络/焊盘栈，过孔/钻孔位置/跨层/镀覆属性，走线 LINE/ARC 实际宽度/端点/网络，圆弧中心/半径/方向，标准圆/矩形/闭合铜盘、PLACE_BOUND、明确 V-CUT 层，以及 COMP_HEIGHT/封装/料号。

实际孔尺寸使用 NC 语义 DRILL_HOLE_NAME/NAME2，不用 DRILL_FIGURE 图例尺寸。机械/激光工艺仍未知，不凭孔径推断。
不支持的图形、开放/多轮廓板框与缺属性明确为覆盖缺口；PLACE_BOUND 不自动认证本体。只有原生生成 Gerber 自动确认对象对齐。
未找到明确 V-CUT 层不自动认定本板没有 V-CUT；无切线的适用性可通过工程师确认对象 JSON 补充。

## 铜厚

叠构表分别显示 BRD设计、成品确认、采用值及依据/日期。
选铜层 → “确认/覆盖所选层成品铜厚” → μm 与板厂/工程师/文件备注；可恢复设计值。
顶/底面分别选能力档，全局外层输入保留。确认随当前分析和报告保存，尚无独立项目保存。

## SMT 操作

1. 导入 BRD，执行 PCB 分析。
2. SMT 页启用“自动关联 PCB 导出 / Gerber / BOM”，导入同版 BOM。
3. Gerber 优先本次 PCB 产物；也可导入 SMT Gerber 目录。外部资料需确认同版同原点，否则相关检查待复核。
4. 执行 SMT 分析，后台生成 BRD 哈希绑定对象 JSON，执行供应商/内部基线算法。
5. “资料关联 / 分面完整性”查看位号、封装/面别/料号冲突、DNP、轮廓/高度来源与 TOP/BOTTOM 完整性。报告新增“资料关联”。
6. 已确认的对象 JSON 优先使用，不以自动候选覆盖。

### BOM 补充列（mm）

支持 CSV/XLSX。模板 `templates/smt_bom_attributes.csv` 只有表头，没有示例值：

| 列 | 含义 |
|---|---|
| category / 封装类别 | 明确 chip_0402、chip_0603、chip_0805、qfn、qfp、bga 等；不猜任意名称 |
| height_mm | 明确器件高度；缺失可读取 BRD COMP_HEIGHT 设计值 |
| body_length_mm / body_width_mm | 已确认本体长宽 |
| body_confirmed | YES 表示本体尺寸已确认 |
| body_origin_centered | YES 表示放置原点为本体中心，否则不能凭长宽生成本体矩形 |
| DNP | 明确 YES/NO；空白未知，不默认贴装 |
| global_mark / tooling_hole / test_point | 明确用途 YES/NO；不凭前缀或圆图形猜用途 |

本体尺寸与中心原点已确认则按 BRD 旋转生成本体轮廓，否则 PLACE_BOUND 保留复核。
冲突不生成确认本体。DNP 从贴装检查排除，但铜焊盘不删除。
Mark/测试点尺寸来自铜盘，定位孔精确关联孔记录；声明对象缺图形仍为未获取。
测试点可接触直径采用铜盘质心内接圆保守值，不用包围盒宽度冒充可接触圆直径；原生记录仍需核对阻焊开窗是否暴露该盘。
Gerber 不包含类别/高度/DNP 语义，不能凭底片补造。

## 边界

不是完整商业 DRC、阻抗求解或制造认证。不完整本体、用途、类别、对齐、高度与缺能力均保持复核。
对象、BOM、Gerber、BRD 和 PCB 产物前后核对指纹，报告导出前复查。
