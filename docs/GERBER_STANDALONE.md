# PCB 统一界面与 Gerber 独立分析（2026-11-25）

修改项目仅为 `D:\Evan\MPA-DFM\MPA-DFM`，与 SCH-AI 无关。

## 使用

1. 打开新版 `Evan_MPA_DFM.exe`，默认显示 **PCB 分析 · BRD / Gerber**，右上显示构建标识 `20261125-PCB-Compact-R4`。
2. 点击 **导入文件**（BRD / Gerber / 压缩包）或 **导入目录**（Gerber）。也可在左侧粘贴路径并点击读取。
3. 查看“导入图层清单”，确认图层角色和读取错误。建议使用独立目录下同版本的一套铜层、阻焊、丝印、板框及 NC Drill。
4. 选择板厂、板型、能力等级、外层成品铜厚；填写实际铜层数，或导入逐层叠构 JSON。内层铜厚缺失不会套用外层铜厚。
5. 点击 **执行 PCB 分析**。查看共用的制程能力比对、问题 X/Y 坐标、几何覆盖与缺数据。
6. 使用 **图形预览** 查看真实底片叠图和编号坐标；使用 **导出 PCB 报告** 导出。Excel/CSV 选项和报告预览在 **设置 / 工具** 中。

无需 BRD、Cadence 或 Artwork 导出器。支持 RS-274X/X2 单文件、目录、ZIP、TAR/TGZ（包括压缩包内的子目录）。
常见扩展名含 `.gbr/.ger/.gerber/.grb/.gbx/.pho/.art/.gtl/.gbl/.gts/.gbs/.gto/.gbo/.gko/.gm1/.gtp/.gbp/.gN`。
对于未知扩展名，还会检查 Gerber 格式头；不能把其他文件改扩展名后作为有效 Gerber。

## 界面变化

- 主操作保留：导入文件、导入目录、执行分析、问题预览、报告导出。
- BRD 和 Gerber 使用同一个资料区、参数区、结果区，不再分别占两个 PCB 页签。
- 仅导入 Gerber 时独立分析；仅导入 BRD 时默认原生导出制造资料；BRD 已导入后选择同版 Gerber 目录，保留 BRD 并使用配套底片。
- 如果要切换为另一套独立 Gerber 文件/压缩包，先点击 **清空资料**，避免把新底片错误绑定到旧 BRD。
- “打开 BRD”、坐标脚本、导出器设置集中在 **设置 / 工具** 窗口，不挤占 PCB 主界面。
- 主界面固定布局：左侧资料和能力/叠构/参数；右侧简短结论、结果列表和位置。不会因问题数量或判定依据长度扩张。
- 结果默认显示不符合/待复核，每页最多 100 项；通过、信息/缺数据可切换筛选。位置也分页，完整数据保留在分析结果和报告中。
- 判定依据使用独立详情窗口，选中记录在列表下方显示完整说明；分析完成不再自动展开 BRD 参数。
- 移除“导出 Gerber”独立按钮和“需要独立 PCB 报告”开关；Gerber 报告分析后直接可用。
- SMT 和阻抗高亮保留自己的功能页签；分析分支依据已导入资料，不受页签选择影响。
- 不在启动时自动加载历史 BRD。

## 叠构示例

```json
{
  "layer_count": 4,
  "stackup": [
    {"index": 1, "name": "TOP", "copper_um": 35},
    {"index": 2, "name": "L2", "copper_um": 18},
    {"index": 3, "name": "L3", "copper_um": 18},
    {"index": 4, "name": "BOTTOM", "copper_um": 35}
  ]
}
```

几何配置可使用已有 `dfm_geometry.json`（目录内自动读取），或通过“选择几何配置 JSON”选择外部文件；外部文件可直接为几何选项对象或包含 `geometry_options`。
外部 JSON 的 `drill_directory` 相对路径相对于该 JSON；目录内配置相对于底片根目录。压缩包内配置同样以包根目录为基准。
带 `brd_sha256` 的 BRD 专用配置不能用于独立 Gerber 分析。

## 正确性与边界

- 读取最终极性、区域和孔径宏图形，按现有引擎检查线宽/线距候选、铜到板边、阻焊桥、丝印及适用的钻孔规则。
- 图层未知、同层重复、解析错误、缺少板框/叠构/钻孔元数据和扫描预算耗尽都显示覆盖缺口，不静默放行。
- Gerber 不等于完整网络/焊盘栈/器件数据库；部分几何检查仍为候选扫描，不能据“没有发现问题”证明整板可投产。
- Gerber-only 坐标为 mm，不生成 Allegro 跳转命令，也不从焊盘形状猜器件位号。
- 导入、分析及报告导出校验输入 SHA-256；输入变化后必须重新导入/分析。
- ZIP/TAR 使用路径、链接、大小和数量限制，不直接 extractall。
- 报告不能覆盖输入文件或写入被分析底片目录，避免污染输入快照。
- 原业务文件、旧发布目录均保留不变。

命令行打开资料：`Evan_MPA_DFM.exe --gerber "D:\CAM\board.zip"`。
发布验收：`Evan_MPA_DFM.exe --check-gerber-ui "D:\验收\gerber.json"`（仍执行正常授权检查，使用合成底片）。
