# R8：SMT BOM 核对与 Issue summary 问题图片

构建标识：`20261127-SMT-BOM-IssuePictures-R8`。

## BOM 导入

在 SMT 页点击“导入 BOM 表”，支持 CSV、TSV、TXT、XLSX、XLSM。后台只读解析，不执行宏。
导入成功显示位号数量；格式错误不替换之前的有效选择。“清除 BOM”取消当前关联。
点击执行 SMT 分析，所选 BOM 在自动对象关联、参数比较、手工对象 JSON 模式下均参与核对，不会因为关闭自动关联而静默忽略。

核对位号、封装、面别、明确 DNP、同料号多封装；CAD 多出的位号或 BOM 缺失需要核对非贴装/机械/文档对象，不能直接删除。
缺类别、高度、本体边界或未知 DNP 仍为复核，不用名称猜真实属性。结果显示 BOM 数量与核对问题；报告新增“BOM核对”。
BOM 内容前后及报告导出前校验，变更后拒绝旧报告。

## 问题图片

- PCB 报告 `Issue summary` 新增“问题图片、图片来源/状态”。
- SMT 报告新增同名页，包含对象问题与 BOM 核对问题。
- 综合 DFM 报告新增未加前缀的 `Issue summary`，联合 PCB/SMT 问题；原分项页仍保留。
- 有可靠毫米坐标与对应 Gerber，渲染真实底片局部 PNG，红框标记问题位置；有已确认对象资料时绘制实际本体/铜盘/占位边界和位号。
- PLACE_BOUND 明确标记为占位轮廓，不是本体认证；底面保留 BRD 原点/轴向，不额外镜像。
- 缺坐标、缺图形、未确认外部 Gerber 对齐、解析失败等显示未生成及原因，不生成替代示意图。
- 每个规则/面显示一个代表位置，全部位置仍在问题明细；每汇总页最多 200 张图片，超限仅停止图片输出，不截断问题。
- Excel 图片嵌入文件，不依赖报告旁的 PNG；行高、列宽和分页续行会保持图片锚点与问题对应。
- CSV/TXT/JSON 保留问题和来源；CSV/TXT 不支持嵌入图片。

## 依赖与验收

新增 Pillow 依赖并取消 PyInstaller 对 PIL 的排除，后续新 EXE 会包含图片支持；旧交付 EXE 不会自动加载源码变化。
验证包括 XLSX 媒体数据、保存读回、续行锚点、缺图原因、综合报告及选定 BOM 在非自动模式仍执行核对。
真实样例保存在 `output/r8_bom_issue_pictures/`：

- `894_PCB_issue_pictures.xlsx`：90 条报告问题，26 张局部图；其余缺图片依据时保留说明。
- `739_SMT_BOM_issue_pictures.xlsx`：读取项目内 183 位号 BOM，核对问题保留，70 张对象局部图。

样例是当前输入/规则的检查结果，不表示整板通过，不照搬外部 Valor 报告阈值。
