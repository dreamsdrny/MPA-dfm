关键学习：
- Via到铜盘不是钻孔孔壁距离；同网/异网门槛分别确认。4mil=0.1016mm，6mil=0.1524mm。
- 传送边明细有主面/次面之分；200mil=5.08mm，但不能把任意板框最短距离当实际轨道边。
- 160mil=4.064mm，与专家的4mm并不完全一致；测试点到Mark还需确认中心距或铜边距。本次新算法为铜边距。
- 孔内填孔、屏蔽罩焊盘禁止Via、热焊盘需要0.35/0.4mm排气孔是不同工艺。不能统一禁止或统一允许。
- 明细统一写mil，但 `Toeprint covered by Surface (%)` 是百分比；Fiducial/Hole in SMD是数量；BOM缺位号/Short/Placement mismatch是类别证据。`Non-uniform SMD pads size`原始值可达76311.202，厂商统计定义不明，不自动换成mm或本程序面积差比例。
- Short detected需要网络、net-tie及跨层完整性；本程序PCB已有同层异网铜连通候选，不冒充Valor全板短路认证。

## 本轮新增16个装配检查生命周期（共40个）

1. 前趾下限、后跟上限、实体引脚横向宽差（同一类）；保留已有前趾上限及后跟下限。
2. 确认两焊端铜盘面积差：`(max-min)/max`，仅几何/工艺复核，不等同厂商统计或热仿真。
3. 器件到屏蔽罩：确认wall/skirt方可硬判；整罩投影可能覆盖正常罩内器件，仅候选。
4. TOP/BOTTOM分面高度：各面设备门槛；BRD设计高度仅复核，有来源实物/确认BOM高度才硬判。
5. 实际传送线段/工艺边距离：不从包围盒猜轨道。PLACE_BOUND仍只给复核。
6. 同面测试点到Mark铜边距离。
7. 测试点到同网/异网器件铜盘距离。
8. Via真实铜盘到同网/异网SMD铜盘距离（带空间索引）。
9. 不同器件SMD铜盘间距，排除同器件及明确DNP。
10. 裸铜到裸铜：最终铜与阻焊开窗交集，仅候选。
11. 裸铜到其它铜块阻焊覆盖部分；排除同一铜块正常焊盘出线，避免每个焊盘都误报。
12. 直线走线宽度与焊盘沿走线法向的投影宽度比较；圆弧暂不硬判。
13. 完整原生丝印文字与明确板号/版本串严格核对；不猜文件名。
14. 有来源镭雕区与实际孔/跨度相交检查；不声称二维码扫码等级/白油厚度已检测。
15. 热盘所需开孔/填孔盖铜/禁止孔策略；NPTH不当排气Via，未知清单不当无孔。
16. MPN绑定确认模型与明确CAD封装代码/第一脚映射；不从MPN文本猜尺寸，不从CAD焊盘生成实体引脚。

新增BOM/CAD核对：即使BOM封装列为空，也检查同一料号在CAD出现多个封装。自动关联现在保留MPN、BOM高度来源、真实Via铜盘及原生丝印文字。

## 使用与资料合同

1. 从新目录启动 `Evan_MPA_DFM.exe`，保留同目录匹配的 `license.json`。
2. 导入BRD后到SMT页，可关联BOM/Gerber/PCB提取资料。后台extracta读取；分析/导出不启动PCB Editor。只有明确定位/高亮操作才允许打开Editor。
3. “生成装配补充规则模板”或使用交付 `assembly_rules.json`：全部新门槛null，填写当前产线确认值、`source`和版本。不自动选择历史报告三档中的任何一档；比例键为0..1。
4. “生成对象资料模板”后填真实机械/实体资料，再导入对象JSON。JSON绑定当前BRD SHA-256及mm原点、镜像、旋转确认。完整性默认false。手工对象文件优先，自动关联不覆盖它。
5. 新检查在“装配补充检查/缺口”和报告显示；`Issue summary`可用已确认对象/Gerber绘局部图，无真实坐标/几何则明确不生成。

新增对象示例（仅格式，不是当前板真实证据）：

```json
{
  "conveyed_edges": [{"points": [[0,0],[0,100]], "assembly_sides": ["TOP","BOTTOM"], "confirmed": true, "source": "已确认拼板图"}],
  "laser_regions": [{"id": "QR1", "side": "TOP", "outline": [[10,10],[15,10],[15,15],[10,15]], "confirmed": true, "source": "二维码工艺图"}],
  "thermal_pads": [{"refdes": "U1", "pin": "EP", "side": "TOP", "outline": [[20,20],[22,20],[22,22],[20,22]], "confirmed": true, "source": "当前器件工艺确认", "via_policy": "required_open"}]
}
```

以上片段必须合入GUI生成的完整对象模板，不是可单独导入的板证据。`thermal_pads.via_policy`支持`required_open`、`required_filled_capped`、`forbidden`。热孔是否0.35/0.4mm、数量、热性能仍需器件工艺复核；本轮不自动锁定该尺寸。

实体引脚在 `components[].physical_leads`提供confirmed、pin、outline、toe_direction和no_solder；`no_solder:false`才允许新尺寸检查硬判。实体模型在同器件提供 `manufacturer_part_number`、`cad_package_code`、`cad_pin1`和`part_model:{confirmed:true,source,mpn,package_code,pin1}`。第一脚核对是明确映射标签检查，不能替代空间方向/极性认证。
