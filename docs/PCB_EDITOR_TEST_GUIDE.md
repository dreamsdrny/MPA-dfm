# PCB Editor 联动测试说明

版本：`20261126-PCB-Extracta-Copper-R6`

## 启动

- 双击同目录 `Evan_MPA_DFM.exe`，保留配套 `license.json`，不要使用旧包许可证。
- 本版保留正常授权校验，不需要安装 Python。CAD 联动需要安装并授权 Allegro / OrCAD PCB Editor。
- 本版与旧包独立存放；请确认右上角构建标识为本版本，避免继续测试旧 EXE。

## 测试一：PCB 分析后台取坐标/铜厚，不打开 Editor

1. 导入真实 BRD，等待导入完成。
2. 点击“执行 PCB 分析”。后台 extracta 提取坐标/叠构，然后自动检查；不应出现 PCB Editor 窗口。
3. 查看“设计信息（只读）”中的层名、逐层铜厚和数据来源。缺失应显示未获取，不默认填 35 μm。
4. 查看“BRD 器件 X/Y”是否有真实元件坐标、旋转和面别。顶底面阻焊桥分别按各自铜厚选能力档。
5. 对有坐标的问题双击，观察 PCB Editor 是否缩放到对应位置；确认状态为“已定位选中问题点”。
6. Gerber 未确认与 BRD 原点一致时不会强行跳转，应使用 Gerber 预览。

后台提取需要本机 Cadence 的 extracta.exe；未安装或提取失败不强制打开 Editor。缺资料可在“待补充资料”填写，或导入板厂确认叠构 JSON。设计叠构铜厚不是实测成品铜厚。

## 测试二：走线查找

1. 导入 BRD 后打开“Allegro 走线查找 / 高亮”页签。
2. 确认只剩“寻找铜层、线宽、线距”三个输入。
3. 选择实际铜层，先填已知线宽（mil），线距留空。
4. 点击“在 PCB Editor 查找并高亮”，查看是否自动打开当前 BRD 并显示匹配段数和临时高亮。
5. 再测试线宽 + 线距同时筛选。重新查找前，关闭上次查找打开的 Editor；程序不会关闭其他 CAD 窗口。
6. Allegro 中保持结果面板打开观察；Clear / Close 清除显示。不保存 BRD。

线距是所选层内走线段到其他网络走线段的最小铜边距离，不包含焊盘、过孔或铜皮。固定匹配容差 0.01 mil，不是阻抗认证。
