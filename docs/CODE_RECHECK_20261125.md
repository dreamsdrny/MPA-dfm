# 代码复查与修复记录（2026-11-25）

## 已确认问题及修复

1. **BRD 结构检查不足**：普通文本拼接任意 ZIP 会被当作有效设计。现在要求可解析的 `Header.xml` 和至少一个含命名对象的已识别设计 XML，并拒绝损坏的已识别对象 XML。这只是最低结构检查，不能证明文件由 Allegro 生成，也不能保证覆盖所有版本的合法 BRD 格式；其他实际板型仍需验证。
2. **几何快照缓存失效**：同大小、相同修改时间的 BRD 替换后可能返回旧快照。取消基于文件状态的跨调用缓存，同次 BRD 提取使用已读入的原始字节并共享解码结果。
3. **外置钻孔资料未纳入版本检查**：显式几何配置、Gerber 目录中的 `dfm_geometry.json`、自动导出 Gerber 后指定的外置钻孔目录均纳入分析前后指纹和导出前复核。分析时几何 JSON 被改动也会拒绝结果。
4. **SMT 对象资料仅用大小和时间发现变化**：增加对象 JSON、关联文件和 Gerber 的 SHA-256 指纹；分析前后及后台导出时复核。UI 的定时刷新仍使用轻量文件状态检查，同大小且时间不变的修改可能不会立即在界面中失效，但导出时会拒绝。
5. **报告覆盖竞争和来源变化**：报告生成后再次检查输入，提交时使用排他创建，避免覆盖竞争者的文件；失败时尝试按文件身份回滚已创建的部分文件。报告目标不得位于已记录的资料目录或覆盖源文件。多个附属文件的提交不是原子事务，执行中仍可能短暂看到部分文件；异常回滚也可能因系统权限或外部占用而失败。
6. **解压及配置读取预算**：BRD 条目解压受单条及剩余总预算限制；SMT 配置、对象 JSON 和 PCB 几何配置采用有界读取。不同分析器仍有各自的输入及计算限制，不代表任意大型资料都能安全完成。
7. **阻抗插件结果一致性和界面状态**：检查结果中的板、层、筛选模式、走线类型及插件会话，异步读取期间切层或更换目录时丢弃旧结果；数值参数规范化后再送往 SKILL。对象列表过长时提示截断，空约束不视为已确认阻抗。
8. **界面导出版本绑定**：PCB/SMT 导出检查导入 BRD 的内容哈希；生成过程中输入变化时提示报告属于开始导出时的快照。报告预览生成期间若输入变化，不打开旧预览。

回归测试见 `tools/test_recheck_20261125.py`、`tools/test_pcb_analysis_service.py` 及 `tools/test_impedance_plugin.py`。测试使用隔离临时目录和模拟输入。

## 限制及部署提示

- SHA-256 前后比对可以发现保留到检查时的变化，但不能排除文件在两次检查之间变化又恢复的竞态；报告提交也不是多文件原子事务。
- 部分 BRD 解析依赖内嵌结构及推断，格式不符或数据不足需提示用户人工核对，不能把结构通过当作真实 CAD 验证。
- 原生 Allegro PCB Editor/Artwork、插件高亮与制造数据导出仍需在有许可的实际环境中验收；模拟及 `cnskill` 加载测试不等于实机验收。
- 此次仅修改源代码和测试，既有交付 ZIP/EXE 没有重新打包，不包含本次改动。
