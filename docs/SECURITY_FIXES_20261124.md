# 代码修复与闪退排查

本轮依据 `CODE_AUDIT_20261124.md` 修复用户列出的风险，保留原始审查报告，不覆盖旧交付。

## 本轮改动

- 旧约束脚本拒绝无法安全嵌入的名称和非有限/非数字参数，不再在加载时自动执行；旧约束 API 未经当前 CAD 验证，使用前必须在隔离副本人工核实。
- BRD 输入、单个内嵌条目、条目总量/数量以及快照解压增加上限。`.Z` 无可控输出长度的解码器增加保守预检查：可能拒绝部分合法大文件，需要先在隔离环境解压为普通文件；超限不会报告为通过。
- 正式工作台不再把文本特征后备解析当成有效 BRD。老版本纯二进制缺少受支持结构时会明确拒绝，需由 PCB Editor 导出或人工确认。
- BRD 导入、分析和报告链路增加 SHA-256 内容核对；外部 Gerber/ODB、补充 JSON 和指定坐标目录分析前后与报告导出前复核。路径/size/mtime 只用于界面快速失效提示。
- 外部 Gerber 预览写入应用临时目录，不覆盖客户底片目录；报告的主文件和所有 sidecar 若已存在一律拒绝覆盖，请使用新文件名；不可写入源资料目录。
- 综合 DFM CSV 保留 PCB 和 SMT；供电子表格打开的 CSV 对可能的公式字符串加单引号，BOM 机器用途可显式 `spreadsheet_safe=False` 保留原始值。
- SMT YAML 拒绝重复键，记录实际规则文件哈希，分析与导出前后检查；重复字段的内部基线对比不再取最后一个，改为复核。
- 原生阻抗插件采用完整设计路径而不是仅板名；未解析阻抗覆盖不判为匹配；导出完成记录带字节校验（非密码学认证）；Pick 不将跨回调旧间距声称为当前实测。
- 新增 `%LOCALAPPDATA%/EvanMPA_DFM/logs/Evan_DFM_crash.log`，记录 Python 回调/后台异常和 faulthandler 可捕获的致命错误；关闭主窗口时若任务仍在执行会提醒等待。

## 重要限制

- 用户反馈“分析/导出时闪退”，本机未找到旧版本崩溃日志，也未复现同一真实操作，因此**不能宣称已经确认并根治该闪退**。某些本地库/进程被操作系统强杀的情况也可能无法写入日志。
- 真正的 Allegro 设计未保存编辑、跨回调 dbid 与所有 Constraint Manager 优先级不能仅凭路径/校验和保证；本机此前 PCB Editor 原生探测失败，真实高亮/间距/拾取仍需有许可的目标环境验收。
- 内容校验不是签名；不可信的本地操作者可以同时重写数据与完成标记。外部 Gerber 与 BRD 的同版、原点/镜像仍需可验证的工程证据，不因文件哈希未变化就证明它们属于同一个设计版本。
- 故障再次出现时，请回传上述崩溃日志、使用的 EXE 版本、操作顺序以及故障板/资料可分享范围；没有授权前不上传客户设计。
